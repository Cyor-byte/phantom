phantom.faces¶

Face detection, landmarks, encoding, comparison, grouping and age and gender estimation. Everything documented on this page can be imported directly from phantom.faces, for example from phantom.faces import detect.

Functions and classes¶

Wraps dlib’s face detectors and face encoder.

Support for other detectors could be added in the future.

Important links:

http://blog.dlib.net/2017/02/high-quality-face-recognition-with-deep.html http://dlib.net/face_detector.py.html http://dlib.net/face_landmark_detection.py.html http://dlib.net/face_recognition.py.html https://github.com/davisking/dlib https://github.com/davisking/dlib-models

class Face(encoding=None, image=None, origin=None, landmark=None, location=None)[source]¶

This is a convenience class that helps to gather, in a single place, the encoding, landmarks, image, and origin of a face.

In time we may use this class to transparently replace some conventions of phantom.

Parameters:

  • encoding – a 128-d vector encoding for a face

  • image – an np.ndarray/cv2 image

  • origin – path to a file

  • landmark – a Shape object, that describes the landmarks of the face

  • location – location as (left, top, right, bottom) of a face within origin

class Atlas(elements, path)[source]¶

A large grouping of facial encodings.

Parameters:

  • elements – list of Face objects, which at least have an encoding

  • path – the path to which the atlas will persist on disk

fit(*, do_grouping=True)[source]¶

Used clustering algorithms to group all the faces of the Atlas into distinct groups. These can later be used to match new faces, or compare to other Atlases.

group()[source]¶

Sets up the Nearest Centroid classifier so predictions can be made of new encodings against the found (or eventually edited) clusters.

Should always be run after calling Atlas.group().

predict(needles)[source]¶

Quickly search the faces (encodings) in needles against the grouped centroids. This gives an extremely fast way of approximate search over the grouped faces.

Parameters:

needles – list of 128-d vector encoding for a face

encode(img, *, bgr=True, locations=None, model=Shape68p, jitter=1)[source]¶

Detects and encodes all the faces in an image.

Wrapper of dlibs resnet facial encoder.

Parameters:

  • img – numpy/cv2 image array

  • locations – list of tuples (left, top, right, bottom) with face locations

  • model – shape predictor

  • jitter – an integer number of times to scramble the image a bit, and re-run the encoding. Higher jitter makes for slightly better encodings, though it slows down the encoding.

compare(face1, face2)[source]¶

Compares two face encodings (from dlib/phantom.faces.encodings).

A distance under 0.6 means the faces correspond to the same person. A distance slightly over 0.6 (+epsilon) means it could be the same person, for a low enough epsilon. Distances over 0.6 mean the faces are of different people.

Parameters:

  • face1 – dlibs 128-long face encoding

  • face2 – dlibs 128-long face encoding

Returns:

float, distance between face1 and face2

estimate_gender(face)[source]¶

Estimates a characteristic based on the face that is passed.

Parameters:

face – dlibs 128-long face encoding

Returns:

float, estimated gender. The gender model has been trained as value 1 for females, and -1 for males. So, a value of -0.5 means “mainly male” and can be considered as such. Values between -0.3 and 0.3 mean the model is not certain enough, and should be considered as “unknown” or “uncertain”

Age groups¶

phantom.faces.age_tags¶

List of (lower age, higher age, description) tuples. The value returned by estimate_age_onnx() is an index into this list. The first element, (-1, -1, "none"), is a placeholder and is not used.

perspective(base, dest, baselm, destlm, *, inter=cv2.INTER_CUBIC)[source]¶

Aligns dst with respect to base, calculating an homography between them and using a perspective transformation (cv2.warpPerspective).

Parameters:

  • base – base image, taken as reference frame

  • dest – image to be modified

  • baselm – phantom.faces.Shape object describing a face in base

  • destlm – phantom.faces.Shape object describing a face in dest

  • inter – interpolation algorithm from cv2 (see cv2.INTER_ constants)

Returns:

dst, warped to match the base image (according to baselm and destlm)
