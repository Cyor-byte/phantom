class Grid(panels, size)[source]¶

Represents a grid for grid tranform mappings.

equivalent(other)[source]¶

Tests wether a grid is equivalent to another. That means, that both grids can be mapped between each other.

grid_from_lines(lines, size=(1, 1))[source]¶

Helper function. Creates a Grid object from a sequence of lines. Order in the sequence matters. The assumed direction is top to bottom. All lines must have the same length. A line is expected to be a sequence of at least two tuples of (x, y) points in an image.

No checks are done to see if the resulting Grid is meaningful – that is left as an excercise to the user.

Parameters:

  • lines – list of lists, each being a list of (x, y) points

  • size – numpy style tuple for the shape of the resulting Grid (used when transforming images through grid_transform())

Returns:

Grid object, with panels built from the lines passed

grid_transform(source, grid_src, grid_dst, *, inter=cv2.INTER_CUBIC)[source]¶

Applies a grid transform over an image.

Maps the panels from grid_src to the correspondent panels on grid_dst using perspective transforms.

Parameters:

  • source – source image to transform (ndarray/cv2 image)

  • grid_src – Grid which defines the region-of-interest (ROI) over the source image.

  • grid_dst – Grid which defines the mapping of grid_src over the transformed image.

Returns:
