phantom.measures¶

Camera calibration and measurements on images (vanishing points, planes, heights and distances). The functions in phantom.measures.measure can be imported directly from phantom.measures.

phantom.measures.measure¶

Functions and algorithms related to measuring things in images.

vanishing_points(x1, x2, y1, y2, z1, z2)[source]¶

Calculates de vanishing points in an image. For this, it uses two straight lines in each direction.

Parameters:

  • x1 – Tuple of two points in a straight line, in the X plane

  • x2 – Tuple of two points in a straight line, in the X plane

  • y1 – Tuple of two points in a straight line, in the Y plane

  • y2 – Tuple of two points in a straight line, in the Y plane

  • z1 – Tuple of two points in a straight line, in the Z plane

  • z2 – Tuple of two points in a straight line, in the Z plane

Returns:

List of three elements, each one being the vanishing point in the X, Y and Z planes.

define_plane(x1, x2, y1, y2, z1, z2, height, obj=None)[source]¶

Defines the plane in an image, and the scale factor alfa :param x1: Tuple of two points in a straight line, in the X plane :param x2: Tuple of two points in a straight line, in the X plane :param y1: Tuple of two points in a straight line, in the Y plane :param y2: Tuple of two points in a straight line, in the Y plane :param z1: Tuple of two points in a straight line, in the Z plane :param z2: Tuple of two points in a straight line, in the Z plane :param height: Known height of the object in the image. His base and

top points must be the same used in the parameter ‘z1’, or be specified in the parameter ‘obj’

Parameters:

obj – [optional] Tuple of two points in a straight line, in the Z plane, representing the base and top of the known height object

Returns:

Returns two objects. The first one is the projection matrix (except for the third value, which is just ‘v’), and the second one is the scale factor alfa

estimate_height(alfa, p, top_point_1, top_point_2, bottom_point, img=[])[source]¶

Estimates the height of an object in an image on the same plane (for example the grownd) as the object used to define the plane. Also, draws the intersection between the vanishing line of the bottom and the top of the object, with the vanishing line of the scene if the image is given. :param alfa: Scale factor alfa :param p: Projection matrix (with ‘v’ as the third element) :param top_point_1: Point on the top of the object, creating a straight

line with top_point_2

Parameters:

  • top_point_2 – Point on the top of the object, creating a straight line with top_point_1

  • bottom_point – Point at the base of the object

  • img – [optional] Source image to be drawn on

Returns:

Estimated height of the object

height_parallel_planes(p, zr, alfa, top_point_1, top_point_2, bottom, img=[])[source]¶

Estimates the distance between 2 planes, different from the plane used to define the projection matrix. Also, draws the intersection between the vanishing line of the bottom and the top of the object, with the vanishing line of the scene if the image is given. :param p: Projection matrix :param zr: Distance between the plane used as reference for the projection

matrix, and the bottom plane of the other two

Parameters:

  • alfa – Scale factor alfa

  • top_point_1 – Point on the top of the object, creating a straight line with top_point_2

  • top_point_2 – Point on the top of the object, creating a straight line with top_point_1

  • bottom_point – Point at the base of the object

  • img – [optional] Source image to be drawn on

Returns:

Estimated height of the object

detect_plane(img, obj, height)[source]¶

Detects and defines the space on an image and a scale factor ‘alfa’, based on the detection of straight lines using Canny edge detector and Hough line transform, and the height of an object in said image. :param img: Image used as reference :param obj: Base and Top points of the reference object defined like

((xbase, ybase, z), (xtop, ytop, z))

Parameters:

height – Height of the object

Returns:

Returns two objects. The first one is the projection matrix (except for the third value, which is just ‘v’), and the second one is the scale factor alfa

find_distortion(img, nx, ny)[source]¶

Finds the distortion created by a camera

Parameters:

  • img – Image of a chess board taken by the camera

  • nx – number of inside corners in x

  • ny – number of inside corners in y

Returns:

objpoints[List] of 3D points in real world space and imgpoints[List] of 2D points in image plane

find_and_draw_corners(img, nx, ny)[source]¶

Finds and draws the inner corners of a chess board in the image, if found

Parameters:

  • img – Image of a chess board taken by the camera

  • nx – number of inside corners in x

  • ny – number of inside corners in y

Returns:

True if the chess board was found, and an image with the drawing(in gray scale) False if the chess board wasn’t found, and the original image(in gray scale)

calibrate(img, img_chess_board, nx, ny)[source]¶

Removes distortion of an image created by the camera that took the photo

Parameters:

  • img – Image to be corrected

  • img_chess_board – Image of a chess board taken by the camera

  • nx – number of inside corners in x

  • ny – number of inside corners in y

Returns:

Undistorted image. If the chess board wasn’t found, it returns the origina image (img)
