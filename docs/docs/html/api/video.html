phantom.video¶

Miscelanous utilities that allow to easily work with video.

Mostly wraps OpenCVs classes and functions to give an easy interface. Mostly aimed at making the examples easier to understand.s

threaded_videocap_read(cap)[source]¶
class VideoThreaded(path)[source]¶

Iterable video class, it allows writing code of the form:

>>> vid = phantom.video.Video(path_to_file)
>>> for frame in vid:
>>>     process(frame)

Offloads reading to a separate thread. When reading from files it may speed processing quite a bit.

Parameters:

path – path to the video.
