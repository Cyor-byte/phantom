phantom.utils¶

Utility functions that help in working with the different faces, but are not essential. Includes functions for drawing landmarks, showing OpenCV images with matplotlib, etc.

jpg_ghosts(img, qualities=[50, 60, 70, 80, 90, 100])[source]¶

Implements the JPG Ghosts algorithm as described by Micah K. Johnson and Hany Farid.

Saves img to memory as JPG using different compression levels set by the qualities parameter such that you get to see the “ghost” of parts where the image shows different JPG compression levels. Read the paper for further details.

Parameters:

  • img – cv2/np.ndarray image

  • name – base name to save the different compression level images

  • qualities – (optional) list of ints between 0 and 100, for the different compression levels that will be saved

draw_faces(img, faces, *, color=(0, 255, 0), thick=2, mode='line', on_copy=True)[source]¶

Draw a set of faces over img.

Parameters:

  • img – image on which to draw

  • shape – phantom.faces.Shape object describing a face in img

  • color – a BGR color tuple, or an iterable of BGR color tuples. It’s turned into a cycle before drawing, and iterated upon for each face

  • thick – line thicknes or circle radius, depending on mode

  • mode – draw lines or points over the landmark points

  • on_copy – whether to work on a copy or img directly

Returns:

cv2/np.ndarray

image_grid(images, grid, *, borders=False, colors=None, text_index=False, size=(64, 64))[source]¶

Renders a list of images on a grid. Developed in the first place to check facial clustering results.

Parameters:

  • images – list of cv2 images (np.ndarray)

  • grid – tuple of ints (cols, rows)

  • colors – list of BGR tuples for each element of faces

  • text_index – boolean, indicates if the index must be written on the thumbnail

  • size – thumbnail size, to resize each face found
